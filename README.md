# 鬥地主網站

給同學線上一起玩的鬥地主（含 AI 補位），目前為最小可玩版本：建房/加入房間、叫地主、出牌、簡易局內互動（快捷訊息+丟道具）。

## 本機開發（需要能連外網安裝套件的環境）

```bash
# 後端
cd server
npm install
npm run dev   # 預設 port 3001

# 前端（另開一個終端機）
cd client
npm install
npm run dev   # 預設 port 5173，已開啟 host: true 可供同網段裝置（如平板）連線
```

開發時平板連線方式：確認平板和電腦在同一個 Wi-Fi，瀏覽器輸入 `http://<電腦的區域網IP>:5173` 即可連線（電腦 IP 可用 `ipconfig` / `ifconfig` 查看）。

## 部署到 Render

本專案已附 `render.yaml`，在 Render 建立新 Web Service 時選擇這個 repo，Render 會自動讀取設定：

- Build：安裝並建置前端（產生 `client/dist`），安裝後端依賴
- Start：啟動 Node 後端，後端會同時 serve 前端建置後的靜態檔案

部署完成後，Render 會給一個公開網址，平板直接用瀏覽器開啟該網址即可遊玩，不需要與電腦同網路。

## 遊戲規則

標準鬥地主規則：54張牌，每人17張，底牌3張，叫地主/搶地主，支援單張、對子、三張、三帶一/對、順子（5張起）、連對（3對起）、飛機（帶單/帶對）、四帶二（單/對）、炸彈、王炸。房間人數不足3人時，房主可按鈕讓電腦補位。
